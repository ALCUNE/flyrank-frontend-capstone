## 2. Real Capture vs. AI Choice
- **Decision:** For all work-related showcases (code structure, test results, UI form elements), **real captures** were chosen over AI-generated visual stand-ins.
- **Reasoning:** Authentic project screenshots establish technical credibility and trust. AI UI stand-ins often introduce non-standard UI patterns, broken text artifacts, or unrealistic layouts.

## 3. Rejected AI Image Note (Curation Criteria)
- **Rejected Generated Visual:** An AI-generated abstract digital dashboard graphic intended for the capstone project banner.
- **Reason for Rejection:** The generated image was overly glossy with generic sci-fi glowing nodes, floating code snippets, and meaningless chart vectors. It felt like "generic AI filler" and clashed with the clean, minimal, developer-centric aesthetic defined in the Identity Kit (`#0F172A` text, `#2563EB` royal blue accent).
- **Replacement:** Replaced with a clean, high-contrast code snippet screenshot framed in a minimalist dark-mode container.
