# FlyRank AI - Frontend Capstone Project

This repository serves as my main capstone project for the FlyRank AI Frontend Internship. Over the course of the internship, I will be building and expanding this project to demonstrate modern frontend engineering practices, AI-assisted development workflows, and solid software design principles.

## Tech Stack (Planned)

- **Frontend Framework:** React / Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI Tooling:** Cursor IDE

## Setup & Installation
